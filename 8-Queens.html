مختبر هندسة الأقطار: كيف تعمل المعادلتان b[7 + i - j] و c[i + j]؟

انقر أو مرّر على أي مربع (i, j) في الرقعة أدناه لمشاهدة كيف تشترك جميع المربعات الواقعة على نفس القطر في رقم دليل ثابت، مما يلغي الحاجة لأي حلقة تكرار ويجعل الفحص لحظياً بتعقيد O(1).

حساب الأدلة اللحظي للمربع المحدد

(i = 3, j = 4)
1. الصف الأفقي
a[j] = a[4]

كل المربعات على نفس الصف تشترك في قيمة j.

2. القطر الرئيسي (\)
b[7+3-4] = b[6]

عند التحرك قطرياً (\) يزداد i و j معاً فيبقى الفرق ثابتاً.

3. القطر الثانوي (/)
c[3+4] = c[7]

عند التحرك قطرياً (/) ينقص أحدهما ويزداد الآخر فيبقى المجموع ثابتاً.

لماذا نجمع الرقم 7 في معادلة القطر الرئيسي b[7 + i - j]؟

لأن ناتج الطرح (i - j) قد يكون سالباً! ففي الزاوية اليسرى السفلى (i=0, j=7) يكون الناتج -7، وفي الزاوية اليمنى العليا (i=7, j=0) يكون +7. وبما أن مصفوفات C# لا تقبل أدلة سالبة، نضيف الإزاحة +7 لتحويل المجال من [-7..+7] إلى أدلة موجبة صحيحة [0..14].

المقارنة الأكاديمية بين الدالتين Try1(int i, ref char q) و Try2(int i)

وجه المقارنة Try1(int i, ref char q) Try2(int i)
الهدف من الدالة إيجاد الحل الأول فقط والتوقف فوراً عند تحقق q = 'y'. إيجاد وطباعة جميع الحلول الـ 92 الممكنة للمسألة.
بنية الحلقة التكرارية do { j++; q = 'n'; ... } while ((q == 'n') && (j < 7)); for (int j = 0; j < 8; j++) { ... }
آلية التراجع (Backtrack) تراجع مشروط بـ if (q == 'n') لكي لا يمسح الحل الأول بعد العثور عليه. تراجع غير مشروط في نهاية كل خطوة لإفراغ المسارات والبحث عن الحل التالي.
